# AI Tree Display Overview (WIP)

AI Tree Display is a Unity game engine project. The purpose of this code is to execute the growth loop and visualize 3D tree data produced by the compiled TreeAI engine. 

## Architectural Approach

The overall system follows a Model-View-Controller (MVC) pattern for growing and displaying trees:

- **Model** – TreeAI defines the underlying growth data and behaviors for tree objects.
- **View** – This Unity project serves as the view, encapsulating the display logic and visualization loop necessary to display the data of tree objects grown by the compiled TreeAI library in real time.
- **Controller** – Controller components coordinate between the TreeAI model and the Unity view, issuing growth commands and updating the presentation as the simulation progresses.

By separating responsibilities in this way, the simulation logic in TreeAI can evolve independently while AI Tree Display continues to offer rich, interactive visualization of the virtual trees it produces.

## Getting Started

1. Clone both the TreeAI and AI Tree Display repositories.
2. Build the TreeAI project to obtain the compiled library that exposes the tree growth APIs.
3. Open this Unity project and link it against the compiled TreeAI library.
4. Enter Play mode to visualize and interact with the trees generated by TreeAI.
